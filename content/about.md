I am an Agentic Systems Architect focused on the software around AI systems.
I build the runtimes, workflows, integrations, infrastructure, and safety
controls that turn model capability into something people can operate and
trust.

## What I build

My work includes LLM agents, container runtimes, workflow engines, semantic
retrieval, API integration, CI automation, secret detection, and developer
tools. Rust is my main systems language. I also use Python for AI and data
workflows, Go for services and tooling, and Nushell for automation.

I maintain a broad open source portfolio across agent infrastructure, platform
engineering, code quality, security, and developer productivity. You can find
that work on [GitHub](https://github.com/89jobrien) or read the selected
[project write-ups](@/projects/_index.md) on this site.

## How I work

I prefer clear boundaries, explicit errors, strong tests, and systems that are
easy to inspect when something fails. I use ports and adapters to keep external
services replaceable, and I treat observability and verification as part of the
design rather than cleanup work after implementation.

I am comfortable moving between architecture, implementation, tooling, and
reliability work. I keep communication direct, make uncertainty visible, and
focus on the next useful result.

## Current focus

I am currently working on agent runtimes, governed tool use, workflow tracing,
container infrastructure, and development systems that help people use AI
without losing control of the underlying process.
